# Cyberbullying Detection Project

## Overview
The Cyberbullying Detection Project aims to provide a modern, responsive, and user-friendly website frontend that allows users to detect instances of cyberbullying through text and image inputs. The project focuses on raising awareness about cyberbullying and providing tools for detection and reporting.

## Features
- User-friendly interface for inputting text or uploading images for detection.
- Responsive design that works on various devices.
- Dynamic results display with confidence scores.
- Information pages about the project and its objectives.

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd cyberbullying-detection-frontend
   ```
3. Open `index.html` in your web browser to view the project.
